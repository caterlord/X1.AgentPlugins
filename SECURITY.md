# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, customer information,
or exploit details in a public issue.

Use GitHub's **Report a vulnerability** flow for this repository. Include the
affected plugin version, the client used, a concise reproduction, and the
security impact. Remove access tokens, authorization codes, workspace IDs,
customer data, and other secrets from screenshots and logs.

For an active incident, disconnect the plugin and revoke its X1 authorization.
X1 can independently put the hosted gateway into read-only or disabled mode
while the issue is investigated.
